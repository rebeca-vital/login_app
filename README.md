# Login App - React Native + Expo

Projeto desenvolvido como atividade prática da faculdade utilizando React Native e Expo.

A proposta da atividade era criar uma tela de login contendo:
- imagem/logo
- campos de login e senha
- botão de acesso
- links de recuperação de conta e criação de conta

## Sobre o projeto

Desenvolvi uma interface inspirada no antigo Orkut, utilizando uma versão mais moderna e simplificada para dispositivos mobile.

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript

## Componentes utilizados

- View
- Text
- Image
- TextInput
- TouchableOpacity

## Funcionalidades

- Tela de login estilizada
- Campos de e-mail e senha
- Botão de entrada
- Links de recuperação de conta
- Layout responsivo básico

## Aprendizados

Durante o desenvolvimento deste projeto pratiquei:
- estrutura de componentes
- estilização com style
- organização de layout
- inputs e botões
- utilização do Expo
- conceitos básicos de React Native
